## Overview

The convenience yield — the implied benefit of holding a physical commodity —
is a latent state, observable only through the term structure of futures
prices. Classical approaches assume linear-Gaussian dynamics and never check
the recovered states against the governing PDE.

**AP-PEN** (Affine-Partitioned, Physics-Enforced Network) inverts the two-factor
Gibson–Schwartz model for the instantaneous convenience yield of WTI crude oil
futures. Rather than *penalising* the network for breaching the pricing PDE,
AP-PEN imposes the model's affine coefficients $A(\tau)$ and $B(\tau)$
analytically, leaving a single network to parameterise only the latent
convenience-yield path. The architecture therefore satisfies the PDE by
construction, with no residual loss to learn.

Physics instead enters through a transition likelihood on the recovered path
under the physical measure, together with no-arbitrage and economic inequality
constraints, balanced by a gradient-norm scheme adapted from the WamOL
framework. The estimator is benchmarked against a classical Kalman filter on
both simulated data and real WTI futures (2015–2026).

## Repository contents

```
notebooks/
  monte_carlo_simulation.ipynb   Synthetic Gibson-Schwartz data generator: simulates
                                 P-measure paths, prices the maturity panel under Q
                                 with the closed form, adds observation noise. Retains
                                 the true delta path as the evaluation target.
  AP-PEN.ipynb                   The AP-PEN model: network, loss terms, WamOL
                                 balancing, training and evaluation.
  kalman_filter.ipynb            Classical Kalman filter benchmark (MLE), fit on the
                                 same real WTI panel.

config/                          JSON parameter sets and hyperparameter sweeps the
                                 notebooks load at runtime.

data/input/
  real/                          WTI futures panel from Refinitiv Workspace, with
                                 risk-free rates from FRED (DGS3MO).
  synthetic/                     Monte Carlo dataset written by the simulator notebook.

src/gs_wamol/physics/
  gibson_schwartz.py             Closed-form Gibson-Schwartz futures pricer: the
                                 affine coefficients A(tau) and B(tau), verified
                                 term-by-term against Schwartz (1997) eqs. (18)-(20).
                                 Imported by the simulator notebook.

pyproject.toml                   Package metadata, so `gs_wamol` is importable.
requirements.txt                 Pinned environment (JAX / Flax / Optax).
```

Model outputs — checkpoints, fitted parameters, filtered paths and figures — are
written to `data/output/` and `figures/` at runtime. Both are excluded from this
repository, as they are regenerated by re-running the notebooks.

## Running

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
pip install -e .          # makes `gs_wamol` importable by the simulator notebook
jupyter lab
```

Run `monte_carlo_simulation.ipynb` first to generate the synthetic dataset, then
`AP-PEN.ipynb`, then `kalman_filter.ipynb` for the benchmark. Notebook paths are
repo-relative, so run them from within `notebooks/`.

Two notes on numerics. JAX defaults to float32, in which the PDE residual and
closed-form initial-condition errors floor at roughly `1e-5` — this is a
precision limit, not a training failure. `kalman_filter.ipynb` enables float64
globally, because its MLE recursion compounds error over ~2,700 sequential
steps.
